# S05 — Recommender Systems

S05 develops practical recommender systems using ratings, interaction data, collaborative filtering, content information, and suitable evaluation methods.

## Curriculum overview

| Unit  | Name                                  |
|-------|---------------------------------------|
| BLU10 | Non-personalized Recommender Systems  |
| BLU11 | Personalized Recommender Systems      |
| BLU12 | Recommender Systems Workflow          |

## BLU10 — Non-personalized Recommender Systems

- Understand users, items, ratings, interactions, and profiles.
- Create and inspect rating matrices and understand density and sparsity.
- Build most-rated, top-rated, and summary-statistic recommenders.
- Discover simple item relationships with association rules.

## BLU11 — Personalized Recommender Systems

- Compute user and item similarities for collaborative filtering.
- Define neighborhoods and predict ratings from related users or items.
- Construct item and user profiles for content-based recommendation.
- Generate and filter personalized recommendations.

## BLU12 — Recommender Systems Workflow

- Evaluate recommenders with suitable regression, classification, and information-retrieval metrics.
- Use precision and recall at K, average precision, MAP at K, and rank correlation where appropriate.
- Create train/validation workflows and compare against a non-personalized baseline.
- Build recommender workflows with LightFM and Surprise.
