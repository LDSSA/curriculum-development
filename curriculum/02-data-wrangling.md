# S02 — Data Wrangling

S02 teaches students to ingest, clean, combine, transform, and retrieve data from common real-world sources.

## Curriculum overview

| Unit  | Name               |
|-------|--------------------|
| BLU01 | Messy Data         |
| BLU02 | Advanced Wrangling |
| BLU03 | Data Sources       |

## BLU01 — Messy Data

- Read delimiter-separated files, JSON, Excel workbooks, and HTML tables.
- Handle encodings, malformed lines, unusual delimiters, and inconsistent values.
- Clean strings, replace values, and correct data types with pandas.
- Inspect large files and load selected columns, samples, random lines, or chunks.
- Apply transformations while processing data in chunks.

## BLU02 — Advanced Wrangling

- Write and apply transformation functions.
- Subset and group data, use method chaining, and build custom pandas pipes.
- Combine datasets with concatenation, merge, and join operations.
- Package transformations with `FunctionTransformer` and custom scikit-learn-style transformers.

## BLU03 — Data Sources

- Understand relational and non-relational databases, tables, data types, constraints, indexes, and primary/foreign keys.
- Connect to a database and execute the SQL queries needed to retrieve and aggregate data.
- Understand HTTP requests, responses, headers, GET requests, public APIs, and API authentication.
- Read HTML and extract data with Beautiful Soup and `pandas.read_html()`.
- Account for legal restrictions, JavaScript-rendered pages, and changes to external websites.
