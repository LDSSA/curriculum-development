# S04 — Text Classification

S04 teaches students to represent text as model features and to extract structured information from natural language.

## Curriculum overview

| Unit  | Name                     |
|-------|--------------------------|
| BLU07 | Feature Extraction       |
| BLU08 | Dimensionality Reduction |
| BLU09 | Information Extraction   |

## BLU07 — Feature Extraction

- Clean text with regular expressions and an NLP preprocessing workflow.
- Tokenize text and use stemming, lemmatization, stopwords, and n-grams.
- Represent text with bag-of-words and TF-IDF features.
- Build a text-classification pipeline for sentiment analysis.
- Use Naive Bayes as optional supporting material.

## BLU08 — Dimensionality Reduction

- Select text features using methods such as chi-square.
- Reduce sparse text representations with SVD and understand the relationship with PCA.
- Use word embeddings, spaCy representations, and cosine similarity.
- Treat the mathematical derivation of chi-square as optional material.

## BLU09 — Information Extraction

- Extract information with regular expressions.
- Use spaCy named-entity recognition, matchers, and token patterns.
- Engineer NLP-specific features.
- Combine heterogeneous feature sets with feature unions.
