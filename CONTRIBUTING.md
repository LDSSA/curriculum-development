## Contributing

Start by discussing the proposed change in a repository [issue](https://github.com/LDSSA/curriculum-development/issues).

The Curriculum Team reviews issues, assigns them to the relevant people, and agrees on a due date.

## Pull Request Process

We use [GitHub flow](https://docs.github.com/en/get-started/using-github/github-flow).

1. Create a branch following the naming convention `ISSUE_NUMBER/ISSUE_TITLE`.
2. Update the relevant files.
3. Commit the changes.
4. Open a pull request for discussion and review.

## Approval Process

1. Any Academy volunteer can create and discuss pull requests.
2. Reviews by Teaching, Quality Assurance, and Student Success are optional but encouraged.
3. The Curriculum Team gives final approval, merges the pull request, and closes the issue.

## Specialization Leads

Specialization Leads refine the curriculum as follows:

1. The Curriculum Team develops the specialization curriculum.
2. Specialization Leads review it and propose improvements.
3. The Curriculum Team approves the scope before the specialization team changes the learning materials.
